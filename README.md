# 사진지도 🗺️

사진에 들어 있는 GPS 위치를 읽어 **지도에서 사진을 찾아보는 macOS 앱**이에요.
"그 카페에서 찍은 사진 전부" 같은 걸 지도에서 동그라미 하나로 모을 수 있어요. 블로그 글감 모을 때 쓰려고 만들었어요.

**찾기**
- 지도에서 장소를 누르면 반경 안의 사진이 날짜별·폴더별로 모여요
- GPS가 없는 사진은 같은 날 앞뒤로 찍은 사진으로 **위치를 추정**하고, 여러 장을 골라 **직접 위치를 지정**할 수 있어요
- **촬영 기종별로 보기**: 카메라는 기종별, 휴대폰은 Galaxy·iPhone으로 묶어서 체크박스로 여러 개 고르기
- **동영상만 보기**, 강아지 사진 찾기, 중복 사진 찾기(파일 내용이 완전히 같은 것만)
- 촬영 날짜가 없거나 이상한 사진(라이트룸 내보내기 등)은 폴더 이름의 날짜(예: `190128_여행`)로 보여줘요

**다듬기 · 내보내기**
- **자동 보정**(macOS 자동 보정): 블로그로 끌어다 놓을 때 보정본을 넘기거나, 원본 옆에 `_보정.jpg`로 저장
- **보정 미리보기** 창에서 강도(0~150%)를 보면서 고르기. 사진을 누르고 있으면 원본
- **동영상 → GIF**: 영상을 보면서 구간을 고르고, 용량 제한(기본 10MB)에 맞춰 **여러 장으로 나누거나 한 장에 맞추기**
- 고른 사진을 한 폴더로 **모으기**(바로가기 또는 복사)

**원본은 그대로**: 사진 파일을 고치지 않아요. 직접 지정한 위치는 앱 안에만 저장되고, 보정본과 GIF는 새 파일로 만들어요.

## 필요한 것

- macOS 14 (Sonoma) 이상
- 애플 실리콘(M1~M4)과 인텔 Mac 모두 돼요

## 설치

1. [Releases](../../releases)에서 `PhotoMap.zip`을 받아 압축을 풀어요
2. `사진지도.app`을 **응용 프로그램** 폴더로 옮겨요
3. **처음 한 번만:** 앱을 **우클릭 → 열기 → 열기**를 눌러요

> 애플 개발자 서명을 받지 않은 개인 앱이라, 그냥 더블클릭하면
> "확인되지 않은 개발자" 또는 "열 수 없습니다" 경고가 떠요.
> 우클릭 → 열기로도 안 되면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽의
> **"그래도 열기"** 를 눌러 주세요. 한 번만 허용하면 다음부터는 그냥 열려요.

## 처음 사용

1. 앱을 켜면 나오는 **사진 폴더 선택…** 을 눌러 사진이 들어 있는 폴더를 골라요 (여러 개 가능)
2. 사진 정보를 읽는 동안 잠깐 기다려요. 처음 한 번만 오래 걸리고, 다음부터는 바뀐 사진만 읽어요
3. 지도에서 장소를 누르거나 위쪽 검색창에 장소 이름을 입력해요

폴더는 나중에 **설정(⌘,) → 사진 폴더**에서 더하거나 뺄 수 있어요.

자주 쓰는 동작
| 하고 싶은 것 | 방법 |
|---|---|
| 블로그에 사진 넣기 | 썸네일을 블로그 본문으로 끌어다 놓기 (🪄 아이콘을 켜면 보정본이 들어가요) |
| 보정 강도 정하기 | 사진 우클릭 → **보정 미리보기…** → 강도 조절 → **이 강도를 기본으로** |
| 보정본 파일로 남기기 | 사진 우클릭 → **자동 보정해서 다른 파일로 저장** |
| GIF 만들기 | 동영상 우클릭 → **GIF 만들기…** |
| 기종 고르기 | 필터 줄 오른쪽 **📷 모든 기종** |
| 강아지 분석·중복 검사 | **작업** 메뉴 (여러 개 누르면 차례대로 해요) |
자세한 사용법은 앱의 **도움말(⇧⌘?)** 에 있어요.

## 저장 위치

| 내용 | 위치 |
|---|---|
| 사진 정보 캐시, 직접 지정한 위치, 강아지 구분 | `~/Library/Application Support/사진지도/` |
| 썸네일 | `~/Library/Caches/사진지도/` |
| 모으기로 만든 폴더 | 첫 번째 사진 폴더 안 `_사진지도/모음/` |
| 보정본 저장 | 원본과 같은 폴더에 `이름_보정.jpg` |
| 드래그 보정본·GIF | 임시 폴더 (앱을 끄면 지워져요. GIF는 '다운로드 폴더에 저장'으로 남겨요) |

앱을 지우려면 `사진지도.app`과 위 두 Library 폴더를 휴지통에 넣으면 돼요.

## 직접 빌드하기

Xcode 없이 Command Line Tools만 있으면 돼요 (`xcode-select --install`).

```bash
./build.sh     # ~/Applications/사진지도.app 에 설치
./dist.sh      # 배포용 dist/PhotoMap.zip (애플 실리콘 + 인텔)
```

소스는 `PhotoMap.swift` 파일 하나예요 (SwiftUI + MapKit + Vision + Core Image + AVFoundation).
