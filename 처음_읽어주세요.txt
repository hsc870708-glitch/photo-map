사진지도 — 설치와 첫 실행
========================

사진의 GPS 위치를 읽어 지도에서 사진을 찾아보는 macOS 앱이에요.
macOS 14(Sonoma) 이상, 애플 실리콘·인텔 Mac 모두 돼요.


1. 설치
-------
  ① 이 폴더의 「사진지도.app」을 '응용 프로그램' 폴더로 끌어다 놓아요.
  ② 처음 한 번만: 앱을 우클릭(또는 control+클릭) → 열기 → 열기

  애플 개발자 서명을 받지 않은 개인 앱이라, 그냥 더블클릭하면
  "확인되지 않은 개발자" 또는 "열 수 없습니다" 경고가 떠요.
  우클릭 → 열기로도 안 되면:
    시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"
  한 번만 허용하면 다음부터는 그냥 열려요.


2. 처음 사용
-----------
  ① 앱을 켜면 나오는 [사진 폴더 선택…]을 눌러 사진 폴더를 골라요(여러 개 가능).
  ② 처음 한 번만 사진 정보를 읽느라 시간이 걸려요. 다음부터는 바뀐 사진만 읽어요.
  ③ 지도에서 장소를 누르거나, 위쪽 검색창에 장소 이름을 입력해요.

  폴더는 나중에 설정(⌘,) → 사진 폴더에서 더하거나 뺄 수 있어요.


3. 자주 쓰는 동작
---------------
  블로그에 사진 넣기   썸네일을 블로그 본문으로 끌어다 놓기
                      (🪄 아이콘을 켜면 자동 보정된 사진이 들어가요)
  보정 강도 정하기     사진 우클릭 → 보정 미리보기… → 이 강도를 기본으로
  보정본 파일로 남기기  사진 우클릭 → 자동 보정해서 다른 파일로 저장
  GIF 만들기          동영상 우클릭 → GIF 만들기…
                      (용량 제한에 맞춰 여러 장으로 나누거나 한 장에 맞춰요)
  기종별로 보기        필터 줄 오른쪽 📷 모든 기종
  강아지 분석·중복 검사  작업 메뉴

  자세한 사용법은 앱의 도움말(⇧⌘?)에 있어요.


4. 알아둘 점
-----------
  · 사진 파일은 고치지 않아요. 직접 지정한 위치는 앱 안에만 저장돼요.
  · 앱을 지우려면 사진지도.app과 아래 두 폴더를 휴지통에 넣으면 돼요.
      ~/Library/Application Support/사진지도
      ~/Library/Caches/사진지도

  소스·새 버전: https://github.com/hsc870708-glitch/photo-map
